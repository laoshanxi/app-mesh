# 新员工入职指南

> 示例公司内部文档（Phase 0 演示用语料，内容为虚构）

## 入职第一天

1. 到 HR 处领取工牌和门禁卡，签署劳动合同和保密协议。
2. 领取办公设备：笔记本在 IT 服务台申请，参考《设备申请流程》。
3. 加入企业微信/飞书，部门助理会拉你进所在部门群。

## 常用系统账号

| 系统 | 用途 | 开通方式 |
| --- | --- | --- |
| OA | 审批、公告、报销入口 | 入职当天 HR 自动开通 |
| Jira | 工单与项目管理 | 部门主管在 Jira 后台添加 |
| Git | 代码仓库 | 入职后在自助平台申请 |
| VPN | 远程访问内网 | 参考《VPN 使用说明》 |

## 报销流程

差旅和日常报销统一走 OA：填写报销单 → 上传发票 → 直属主管审批 → 财务复核 → 打款。
单笔超过 5000 元需部门总监加签。详见《差旅与报销制度》。

## 遇到问题找谁

- 电脑/网络/账号问题：IT 服务台（工单系统或分机 8000）。
- 薪酬社保问题：HR 共享服务中心。
- 各业务系统权限：找系统对应的权限管理员，名单见 OA 首页公告。
